## 🛠 Выполненные команды (Лог операций)

1. **Создание структуры (Задание 1):**
   ```bash
   mkdir -p ~/files-lab/sorted/{docs,images,logs,data}
   ```
2. **Переименование файла с пробелом (Задание 2):**
   ```bash
   mv "my report.txt" my-report.txt
   ```
3. **Перенос текстовых отчетов (Задание 3):**
   ```bash
   mv report-*.txt my-report.txt ~/files-lab/sorted/docs/
   ```
4. **Перенос графических файлов (Задание 4):**
   ```bash
   mv *.jpg *.png ~/files-lab/sorted/images/
   ```
5. **Групповой перенос логов (Задание 5):**
   ```bash
   mv app.log* error.log ~/files-lab/sorted/logs/
   ```
6. **Удаление резервных копий (Задание 7):**
   ```bash
   rm *.bak
   ```
7. **Поиск и удаление тяжелых файлов >1Мб (Задание 8):**
   ```bash
   find ~/files-lab -type f -size +1M -delete
   ```
8. **Поиск устаревших файлов и запись в отчет (Задание 9):**
   ```bash
   find . -type f -mtime +30 > ~/files-lab/answers.txt
   ```
9. **Извлечение данных из скрытого файла (Задание 10):**
   ```bash
   cat .secret_data >> ~/files-lab/answers.txt
   ```
