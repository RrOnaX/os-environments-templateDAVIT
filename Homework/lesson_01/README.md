## Итоговая задача: Экспертиза путей службы shop-api

| Текущий путь (с ошибкой) | Правильный путь по FHS | Основание |
| :--- | :--- | :--- |
| `/home/admin/shop.log` | `/var/log/shop-api/shop.log` | Журналы (логи) служб должны храниться в `/var/log/`. |
| `/usr/bin/config.json` | `/etc/shop-api/config.json` | Настройки и конфигурация должны лежать в `/etc/`. |
| `/tmp/database.db` | `/var/lib/shop-api/database.db` | Базы данных — это изменяемые данные, их место в `/var/lib/`. |

## Домашнее задание: Структура каталогов для backup-agent

Таблица распределения файлов согласно стандарту FHS:

| Файл / Данные службы | Каталог по стандарту FHS | Основание |
| :--- | :--- | :--- |
| Исполняемый файл (программа) | `/usr/local/bin/backup-agent` | Программы, установленные вручную вне пакетов дистрибутива. |
| Настройки (конфигурация) | `/etc/backup-agent/agent.conf` | Глобальные конфигурационные файлы службы. |
| Журнал работы (логи) | `/var/log/backup-agent/backup.log` | Журналы и динамические отчеты выполнения процессов. |
| Список сделанных копий | `/var/lib/backup-agent/backups.list` | Постоянные изменяемые данные о состоянии программы. |
| Номер запущенного процесса | `/run/backup-agent.pid` | Сведения о работающей службе до перезагрузки системы. |
| Сами резервные копии | `/mnt/backup-storage/` | Хранение копий на смонтированном внешнем постоянном носителе. |
